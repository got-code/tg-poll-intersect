Connecting and privacy

Use non-anonymous polls in a Telegram group you can access. Get your own API ID and API hash at my.telegram.org/apps. Enter them in the sign-in dialog, followed by your phone number, code and 2FA password if enabled. The app connects directly to Telegram, never votes or sends messages, and may read your chat list to resolve private group links. Telegram may require you to vote first; channel voter lists are unavailable.

“Remember login” encrypts your session and API keys with a separate password. Passwords and Telegram codes are never saved. Reloading clears results and locks the saved login. “Sign out” removes it and attempts to revoke the server session. You can also revoke sessions in Telegram → Settings → Devices. A session has the permissions of your account; Telegram offers no read-only scope. Encryption protects the stored copy, not an unlocked page or a compromised device.

Uses mtcute 0.32.8 by Alina Sireneva / teidesu (MIT), an independent library. This app has not been independently audited. No analytics, CDN or application backend. Open the HTTPS site in your mobile browser. Saved data stays in that browser and does not sync between devices.
